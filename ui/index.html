          Start with your computer

          No more opening KeyVault.exe after a restart. It starts hidden; the vault stays locked until you unlock it here.

          Running KeyVault

          KeyVault runs quietly in the background and keeps working when you close its window. This browser stays signed in (the vault still needs your master password after it locks). Bookmark to come straight back.

          Vault file

          A copy of the previous version is kept next to it as vault.previous.json.

          Delete vault

          Moves the vault file aside (still encrypted) and starts fresh. Only do this if you have a backup or no longer need these keys.

          Connect your AI tools

          Connected tools can see your key names and use keys (write them to a .env file, or run a command with them), but they never see the key values. They can also see and manage your local services.

          ChatGPT in the browser can only connect to servers on the public internet, so it cannot reach a vault on your computer. That is deliberate: use Codex, Claude or another local MCP client instead.

          Activity

          Every time an AI tool used a key or changed a service. Stored inside your encrypted vault.
